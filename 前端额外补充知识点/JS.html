JavaScript 中 00123 为什么是八进制？

在旧的 JavaScript 语法（ES3/ES5）中，以 0 开头的数字字面量会被解析为八进制（octal）。
因此 00123 实际上等于八进制的 123，转换成十进制就是 83（因为 1×8² + 2×8¹ + 3×8⁰ = 64+16+3=83）。
注意： 现代 JavaScript（ES6+）以及严格模式（'use strict'）已禁止这种写法，会直接抛出语法错误。

📌 演示1：非严格模式下的行为

在普通脚本（非严格模式）中：

var num = 00123;
console.log(num);   // 输出 83

现代开发中请使用显式的八进制写法：0o123（表示八进制123，值也是83）。

🔧 正确做法

  • 不要写前导零的数字：需要十进制就直接写 123。
  • 如果真的要表示八进制：使用 0o123（ES6+）。
  • 如果需要保留前导零作为字符串：用引号包起来，如 '00123'。

推荐在项目中配置 ESLint 规则 no-octal 来禁止意外使用旧式八进制。

📝 原文档中的代码问题回顾

你原来的 <script> 中写的是：

var number = '00123'   // ❌ 字符串，不会触发八进制解析
function bool(){
    if(number == 83){   // ❌ 字符串与数字比较，永远 false
        return true
    }
}
console.log(bool)      // ❌ 打印函数本身，不是调用结果

要正确演示八进制效果，应该使用数字字面量 00123（并且确保不在严格模式下），然后直接输出或比较。
